Agents keep to their own jobs.

```
curl -fsSL https://raw.githubusercontent.com/Techneosis/the-crontinental/main/install.sh | bash
```

Running the one-liner again upgrades. The ledger is unchanged, so existing jobs
carry on as they were.

- **An agent can't clear away someone else's jobs.** Inside a Claude Code
  session, `rm`, `disable` and `edit` refuse a job that session didn't book,
  and say who did, unless given `--force`. That covers jobs from other
  sessions as well as the user's own, since a person's permanent jobs are
  usually booked by asking an agent. An agent still manages what it booked
  itself, `enable` is never refused, an edit of only `--note` or `--notify` is
  let through, and outside a session nothing changes. The skill tells agents
  to pass `--force` only when the user named the job. It guards against a
  careless agent; it is not a lock.
- **The repository is now `Techneosis/the-crontinental`.** The installer, the
  one-liner and the skill use the new name rather than GitHub's redirect.
