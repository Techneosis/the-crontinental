Messages can be marked seen, for every device at once.

```
crontinental upgrade
```

The ledger moves to schema v5 on first use (two new columns on the message
book; every existing message starts unseen). Nothing else changes.

- **`crontinental seen`.** `seen 42 [--by phone]` marks a message seen;
  `--through 42` marks everything up to it (a device that has read its list),
  `--all` the whole book. The first mark is kept, with who made it and when;
  marking again is a no-op, not an error.
- **`messages --unseen`**, and `seen_at` / `seen_by` in `messages --json`. The
  plain listing marks an unseen message with `*`.
- **`seen.d` hooks.** The newly seen are announced in one call to each
  executable in `~/.config/crontinental/seen.d/` (`CRONTINENTAL_SEEN_DIR`):
  `CRONTINENTAL_EVENT=seen`, the ids in `CRONTINENTAL_MESSAGES`,
  `CRONTINENTAL_SEEN_BY`, and `{seen_at, seen_by, messages}` on stdin, so a
  device can take down a notification another one already opened. It is a
  directory of its own: your `notify.d` hooks never hear of `seen`.
